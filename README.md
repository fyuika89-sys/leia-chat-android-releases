# Leia Chat · Android releases

Этот публичный репозиторий предназначен **только для APK-релизов Leia Chat** на Android (включая Honor 70).

- Исходный код, интерфейс для ПК и телефона, а также исполнитель задач разрабатываются в приватном `fyuika89-sys/krea-lab`, ветка `feat/leia-chat-unified-20261030`.
- Канонический HTTPS-манифест обновлений: [`leia/update.json`](leia/update.json).
- Первый манифест имеет состояние `no_release`: **подписанного APK пока нет**. Не скачивайте APK с непроверенных сторонних источников.
- После выпуска приложение автоматически проверяет манифест при открытии и периодически, пока активно; скачивает более новый APK, проверяет SHA-256, имя пакета и номер версии.
- Установку новой версии подтверждает владелец в системном установщике Android. Подпись устанавливаемого APK обязана совпадать с подписью установленной версии.

## Для пользователя

После публикации первого подписанного релиза установочный APK появится на вкладке **Releases**. В телефоне чат, инструменты и задачи используют тот же сервер и историю, что и Leia Chat на Windows. Интерфейс Android адаптирован для вертикального экрана: нижняя навигация, крупные области касания, учёт системных отступов и удобное поле ввода.

На момент последнего обновления страницы APK в Releases **не опубликован**. Не следует путать готовые исходники Android-клиента с готовым установочным файлом.

## Для сопровождающего релизы

Не публикуйте в этом репозитории исходники приватного проекта, токены, keystore или пароли. Размещайте только проверенные подписанные APK и манифесты; сохраняйте один и тот же ключ подписи, повышайте `versionCode` и проверяйте SHA-256 по реальному файлу до обновления `leia/update.json`.
